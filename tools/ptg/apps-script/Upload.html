Choose a file exported from VAN: CSV, tab-delimited TXT, or VAN's "Excel" download (.xls), which is tab-delimited text and imports best. The Event Participant Report feeds shift metrics; a list export with survey questions feeds survey metrics. The sheet works out which it is from the column headers. Extra columns are ignored.

No Export button on your report? Select the table on the report page, copy, and paste it here. Repeat for each page; repeated header rows and duplicates are skipped.

Real Excel workbooks (.xlsx): select the "VAN survey export" or "VAN shifts export" tab, then use File → Import → Upload → "Replace current sheet".
